# Linear Algebra

## Course Information

- **Course Code**: MA179
- **Course Type**: Undergraduate major requirement (offered by the School of Mathematics)
- **Credits / Hours**: 3 credits / 54 hours
- **Semester**: Fall 2024
- **Target Students**: First- or second-year undergraduates (Economics, Management, Science, Engineering and Agriculture tracks)

## Course Description

Linear Algebra is an essential mathematical foundation course for science and engineering students. It provides mathematical tools for subsequent engineering computation and scientific research, including matrix theory, vector spaces, and linear transformations.

## Learning Objectives

1. Master basic operations of matrices and determinants
2. Understand concepts of vector spaces and linear transformations
3. Master methods for solving systems of linear equations
4. Understand applications of eigenvalues and eigenvectors

## Course Content

- Determinants and matrix operations
- Linear dependence of vector sets; vector spaces
- Solving systems of linear equations
- Eigenvalues and eigenvectors; matrix diagonalization
- Quadratic forms
