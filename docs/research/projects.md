# 科研项目

## 在研项目

### 广东省自然科学基金面上项目
- **项目名称**：水合物固态流化开采中气-液-固三相流动机理与耦合数值方法研究
- **时间**：2026.01 — 至今
- **角色**：主持
- **研究内容**：
  - 水合物相变动力学与颗粒破碎模型
  - CFD-DEM耦合算法在管流中的应用
  - 实验与数值模拟的协同验证

### 广东省基础研究重大项目
- **项目名称**：极端海洋环境下海上风电平台多场多尺度动力耦合灾变机理与减灾机制
- **时间**：2025.09 — 至今
- **角色**：参与
- **研究内容**：
  - 海上风电基础-海床耦合系统的多尺度分析
  - 极端环境荷载下的灾变机理研究

### 广东省粤港科技创新联合资助专题
- **项目名称**：复杂海洋动力及地质耦合条件下海缆损伤演化与失效预测研究
- **时间**：2026 — 至今
- **角色**：内地牵头

### 山区土木工程安全与韧性全国重点实验室开放课题
- **项目名称**：山区岩体动力破裂的近场动力学-离散元耦合模拟与灾害响应机制研究
- **时间**：2026.01 — 2027.12
- **角色**：主持
- **研究内容**：
  - 近场动力学与离散元（PD-DEM）耦合的高保真数值模拟
  - 复杂节理岩体在强动荷载下的裂纹演化与灾害响应
