# 高等计算力学

## 课程信息

- **课程编码**：CE7225
- **课程性质**：研究生专业基础课（必修，学术学位）
- **学时学分**：36 学时 / 2 学分
- **开课学期**：秋季学期（2023 年秋、2024 年秋）
- **授课对象**：土木工程博士研究生

## 课程简介

本课程面向研究生，讲授计算力学的前沿理论与方法。课程涵盖张量基础、非线性有限元、多尺度建模、高性能计算等内容，培养学生解决复杂工程问题的数值计算能力。

## 教学目标

1. 掌握张量与非线性有限元的理论基础
2. 理解随机场、多尺度等建模方法
3. 了解近场动力学、物质点法等新型数值方法
4. 能够独立开展计算力学研究

## 课程内容

- 张量基础
- 非线性有限元
- 随机场与概率有限元
- 近场动力学（PD）方法：基本原理、求解方法与应用
- 物质点方法（MPM）：基本原理、求解方法与应用
- 光滑粒子流体动力学（SPH）方法
- 计算力学新发展
