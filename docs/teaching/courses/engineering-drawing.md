# 工程制图与CAD

## 课程信息

- **课程编码**：CE115（一） / IC101（二）
- **课程性质**：本科生专业必修课
- **学时学分**：（一）72 学时 / 3 学分；（二）54 学时 / 2 学分
- **开课学期**：秋季学期（2023 年秋季起）
- **授课对象**：（一）土木、水利与海洋工程专业；（二）微电子科学与工程专业（集成电路学院开课）

## 课程简介

本课程讲授工程制图的基本理论与方法，以及计算机辅助设计（CAD）技术。课程着重培养仪器绘图、徒手绘图、计算机绘图三种绘图动手能力，通过线下课堂教学与线上精品慕课学习，使学生掌握在二维平面上表达三维空间形体的方法和技能，加强立体形象思维与空间想象能力。

## 教学目标

1. 牢固掌握正投影的基本原理和绘图的基本技能
2. 具备熟练绘制和读解形体投影图的能力
3. 熟练使用 CAD 软件进行工程绘图
4. 掌握工程制图的国家规范与图样画法，养成严谨制图的工作作风

## 课程内容

**理论部分**

- 制图的基础知识
- 点、线、面的投影；直线与平面的位置关系
- 基本体的投影
- 组合体
- 轴测图
- 截交线与相贯线
- 剖视图与断面图

**CAD 部分**

- CAD 软件操作（9 讲）
- 工程制图国家标准与图样画法
- 规尺作图训练与作业讲评
