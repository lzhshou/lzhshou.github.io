# 离散介质计算方法

## 课程信息

- **课程性质**：研究生专业课
- **开课学期**：春季学期（2026 年春季）
- **授课对象**：土木工程研究生

## 课程简介

本课程讲授离散介质（如颗粒材料）的数值模拟方法，重点介绍离散元方法（DEM）的基本原理与实现技术，以及与其他物理场（流体、热等）的耦合算法。课程结合国内自主研发的离散元计算软件，强调国产化计算方法的自主研发，培养学生对国产工业软件的认识和应用能力。

## 教学目标

1. 掌握离散元方法的基本理论
2. 理解颗粒材料的力学行为
3. 具备 DEM 程序开发能力
4. 了解多相耦合数值方法

## 课程内容

- 离散元方法基础理论
- 颗粒形态表征与建模
- 接触力模型
- 时间积分方法与数值稳定性
- 参数标定与验证方法
- 流体-颗粒耦合方法
- 多尺度耦合方法
- 颗粒介质多物理场耦合
- 机器学习加速离散元计算
- 离散元编程实践

## 考核方式

由读书笔记与计算分析两份报告组成，期末提交并答辩。
