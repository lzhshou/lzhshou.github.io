# 线性代数

## 课程信息

- **课程编码**：MA179
- **课程性质**：本科生专业必修课（数学学院开课）
- **学时学分**：54 学时 / 3 学分
- **开课学期**：2024 年秋季学期
- **授课对象**：大一或大二（经济学、管理学、理学、工学、农学大类）

## 课程简介

线性代数是理工科学生的重要数学基础课程，为后续的工程计算和科学研究提供数学工具。主要内容包括矩阵理论、向量空间、线性变换等。

## 教学目标

1. 掌握矩阵与行列式的基本运算
2. 理解向量空间与线性变换的概念
3. 掌握线性方程组的求解方法
4. 了解特征值与特征向量的应用

## 课程内容

- 行列式与矩阵运算
- 向量组的线性相关性、向量空间
- 线性方程组求解
- 矩阵的特征值与特征向量、矩阵对角化
- 二次型
